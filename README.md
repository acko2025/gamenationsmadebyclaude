# War Of Nations

A grand strategy game that runs in the browser. Lead a nation through the eras: build up your provinces in 3D, research, make alliances and organizations, and wage war.

**Play on a phone:** open the game's GitHub Pages link in Safari (iPhone) or Chrome (Android), then choose **Add to Home Screen**. It then opens full screen and works offline after the first load. Saves are kept on the device.
